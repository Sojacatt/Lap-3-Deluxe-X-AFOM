# Lap-3-Deluxe-X-AFOM
This project aims to improve the forgotten lap system from the level editor "Another Fixed Objects Mod", giving it a more challenging and polished feel based on the Lap 3 Deluxe mod.

Compared to the previous project, ELMDY in AFOM, this one focuses specifically on Lap 3, removing and replacing everything related to Lap 4. Don't worry, Snick.exe is still there, and you can customize most of your Lap 3 experience!

# New object section in the editor!
